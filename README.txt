GSK-STUDIOS PWA

1. Upload all files/folders in this package to the root of your GitHub GSK-STUDIOS repository.
2. Keep index.html at repository root.
3. GitHub Pages -> Deploy from branch -> main -> /(root).
4. Open the Pages URL in Chrome on Android -> menu -> Add to Home screen / Install app.

IMPORTANT:
- This package is the installable app shell.
- AI generation and real payments require a secure backend.
- Never put Stripe/payment secret keys or AI provider secret keys in index.html or a public GitHub repository.
- The price is currently configured as $3/month in CONFIG and can later be changed centrally.
